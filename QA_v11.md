## Как повторить

```sh
node tools/build.mjs                                         # сборка, синтаксис, ESLint
PGHOST=localhost PGUSER=postgres sh supabase/tests/run_tests.sh   # права и правила базы
sh supabase/tests/functions/run.sh                           # функции push и delete-account
```

## Что известно и не сделано в v11

- Казахский перевод — бета: переведены основные экраны (навигация, лента, вход, создание, SOS, сообщения, настройки), часть редких сообщений пока на русском. Нужна вычитка носителем языка.
- Удаление GPS из видео — по стандартным блокам MP4/MOV (udta, meta); экзотические форматы не проверены.
- Сообщения удаленного аккаунта остаются у собеседника с пометкой "аккаунт удален" (решение по ТЗ SEC-05 — согласовать).
- Сроки хранения: ошибки 30 дней, аналитика 180 дней, служебные записи 2 дня (`near_cleanup`).
