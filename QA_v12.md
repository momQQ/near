## Как повторить

```sh
node tools/build.mjs                                              # сборка, ESLint, сжатие
PGHOST=localhost PGUSER=postgres sh supabase/tests/run_tests.sh   # 120 проверок базы
sh supabase/tests/functions/run.sh                                # push, delete-account, проверка медиа
```

## Что известно и не сделано в v12

- Разделение кода по экранам (загрузка только нужного экрана) не сделано: интерфейс — один файл в общей области видимости, разделение требует переработки модулей. Карта MapLibre уже грузится только при открытии карты. Сжатие дало около 17% по gzip: в файлах много русского текста, он почти не сжимается.
- Кластеры на карте рисует MapLibre; на заглушке карты в тестах они не проверяются.
- Казахский перевод новых экранов сделан, но его нужно вычитать носителем языка.
- Демо-тексты публикаций и сообщений остаются на русском: это пользовательский контент, он не переводится.
- `SUPPORT_EMAIL` пустой: пока работает только форма в приложении.
