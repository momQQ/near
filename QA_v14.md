## Как повторить

```sh
node tools/build.mjs                                              # сборка, NEAR Clean в data.js, ESLint, сжатие
PGHOST=localhost PGUSER=postgres sh supabase/tests/run_tests.sh   # 180 проверок базы (v11 + v12 + v14 + гонки + NEAR Clean)
sh supabase/tests/functions/run.sh                                # push, delete-account, проверка медиа, уборка
```

## Что не входит в этап 1 и почему

- **Этап 2 — NEAR Meet** (разделы 11–18, 30–36): мастер встречи, заявки с атомарным приемом, Host-панель, кик, групповой чат, @all/@nickname, готовность, таймер, отзывы. Сейчас "Встреча" создается как публикация категории "встречи".
- **Этап 3 — модерация и антифрод** (разделы 06, 07, 10): очередь `moderation_jobs`, приватный бакет для одобренных файлов, проверка кадров видео, URL-репутация, Risk Score, санкции и strikes, MFA модератора. Фирменная карта (25–29) и 2GIS — после этого.
- **Подтверждение телефона по SMS** не подключено: нужен SMS-провайдер в Supabase Auth. Сейчас повышенный лимит включает администратор.
- **Возрастная проверка**: правила для несовершеннолетних нужно проверить юридически до запуска (ТЗ, раздел 04). Сейчас все аккаунты — "возраст неизвестен", личные чаты с незнакомыми закрыты.
- **Настройки владельца**: ключ Turnstile, `SUPPORT_EMAIL`, `OPENAI_API_KEY` (без него файлы не публикуются).
- **014b (удаление старых имен и пола)** — запускается только по решению владельца.
