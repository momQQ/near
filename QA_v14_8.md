# Проверка v14.8 руками (ТЗ v14.8, раздел 14)

Нужно: staging, 4 аккаунта (Host H, участники A и B, модератор M с TOTP), два телефона (iPhone Safari/PWA и Android).

## AUTH
- [ ] Новый: ник + пароль + почта + правила → "Проверьте почту" → ссылка → профиль активен. До подтверждения — только чтение.
- [ ] Тот же email еще раз → тот же нейтральный ответ.
- [ ] Вход по нику и по почте; неверный ник и неверный пароль — одинаковая ошибка; 5 ошибок — пауза 15 минут.
- [ ] Старый аккаунт без ника входит по почте и выбирает только ник.
- [ ] Перезагрузка, другой телефон, двойное нажатие "Создать аккаунт" — один профиль.

## UI
- [ ] 320 / 375 / 390 / 430 px, Safari, PWA, Android, альбомная ориентация, клавиатура открыта, текст 200%: кнопка публикации видна, ничего не перекрыто.
- [ ] В формах, чате, регистрации и выборе места нет шапки и нижнего меню.
- [ ] Повторное нажатие "Лента" — наверх. "+" всегда открывает 7 типов, черновик — отдельной строкой.

## POST / MAP
- [ ] 7 форм: публикация (обсуждение/объявление), происшествие (вид, время), встреча, событие (начало/конец), акция, помощь, SOS (3 часа, 112).
- [ ] Камера, галерея, до 5 файлов, лимит "Использовано 3 из 3. Снова через 00:28:00", черновик, отказ GPS, назад без потери текста.
- [ ] Выбор места: адрес или "Точка на карте · адрес не определен"; атрибуция карты видна; 600 точек — редкая категория не пропадает.

## MEET
- [ ] 9 категорий: поля, закрепление, приветствие, быстрые действия; горы — предупреждение.
- [ ] Два Host-решения на последнее место — одно проходит. Лист ожидания получает уведомление.
- [ ] Кик: история чата сразу недоступна, место освободилось. Мут на 15 минут.
- [ ] Перенос закрывает запрос готовности; напоминания 24 ч / 1 ч / 15 мин приходят по одному разу.
- [ ] Отмена, завершение, посещение (участник отмечается, Host подтверждает), отзывы 7 дней, без самооценки.

## CHAT
- [ ] Гость читает городской чат, писать — после входа и вступления.
- [ ] @all — только Host/co-host/модератор, раз в 5 минут; @nickname — только этому человеку.
- [ ] Без сети: "Не отправлено · повторить"; после сети — одно сообщение, без дубля.
- [ ] Блокировка скрывает сообщения и упоминания. Старые ссылки #conv= — "Личных сообщений больше нет".

## SEC
- [ ] Мат RU/KZ/EN маскируется, "тебя убью" блокируется, "скиньте на каспи" во встрече блокируется.
- [ ] Закрытые файлы, права двух аккаунтов, апелляция штрафа рейтинга (модератор), допуск к встречам.

## OPS
