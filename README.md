# NEAR — социальная сеть твоего города

Концепт-сайт гиперлокальной социальной сети для Алматы. Три главных сценария: **Узнать** что происходит рядом, **Найти** людей, услуги, события и скидки, **Помочь** соседям.

## Что внутри

- `index.html` — весь сайт в одном файле (HTML + CSS + JS, без внешних зависимостей)
- Интерактивный прототип приложения:
  - Лента с поиском, радиусом, фильтрами, сохранением и статусами публикаций
  - Живая карта с метками и тепловыми зонами
  - Раздел "Открытия": NEAR Radar, SOS, Потеряно/найдено, Услуги, Опросы, События, Скидки с купоном
  - Создание публикации, сообщества, профиль с NEAR Trust и подписками на районы
- Демо-чат NEAR AI, план запуска из 4 этапов, форма "Стань одним из первых 1 000"

Данные в прототипе демонстрационные: публикации и ответы ИИ заданы заранее, форма заявки не подключена к серверу.

## Приложение на телефоне (PWA)

- `app.html` — полноэкранная версия приложения
- `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — установка на главный экран

iPhone (Safari): откройте `.../app.html` → "Поделиться" → "На экран Домой".
Android (Chrome): откройте `.../app.html` → ⋮ → "Установить приложение".

## Как открыть

Откройте `index.html` в браузере или включите GitHub Pages:
Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root`.
