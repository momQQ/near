# NEAR — социальная сеть твоего города

Гиперлокальная соцсеть для Алматы: что происходит рядом прямо сейчас.

- **Сайт:** https://momqq.github.io/near/
- **Приложение:** https://momqq.github.io/near/app.html

## Что работает

- Регистрация, вход, выход, восстановление пароля, редактирование профиля и фото
- Публикации с фото и видео: выбор из галереи или камера, предпросмотр, категория, место (GPS или на карте), скрытие точного места
- Редактирование, закрытие ("неактуально", "вернули хозяину") и удаление своих публикаций
- Лента по радиусу 500 м – 10 км и категориям, "что изменилось за час"
- Карта OpenStreetMap: геолокация, радиус, фильтры, кластеры меток, загрузка только видимой области, карточка публикации, режим списка
- Лайки, комментарии, сохраненное, участие в событиях, добавление в календарь, уведомления
- Radar, события, акции с купоном, потеряно/найдено, поиск
- Друзья: поиск людей, заявки, принятие, удаление; профиль пользователя с Instagram
- Сообщения: текст, фото, видео, голосовые; прочитано ✓✓; предупреждение о незнакомцах
- Безопасность: блокировка, жалобы на публикации, комментарии, сообщения и людей; автоскрытие после 3 жалоб; фильтр мата на сервере; ИИ-проверка фото и сообщений; панель модератора и бан
- Подтверждение email при регистрации и согласие с правилами сообщества
- Установка на телефон (PWA)

## Версия 14, этап 1 (ТЗ v14.4, P0)

- Никнейм вместо имени, фамилии и пола: проверка формата, мата, похожих на официальные, уникальность с учетом похожих букв, смена раз в 30 дней
- Нижняя панель — 5 равных колонок (лента, карта, +, чаты, профиль); "+" открывает "Что создать?": публикация, происшествие, встреча, событие, акция, помощь и отдельно SOS
- Быстрые входы в ленте: встречи, события, SOS, потери, акции, все разделы
- NEAR Clean: мат маскируется на сервере (`Б****`), угрозы не публикуются; тот же алгоритм в приложении, совпадение проверяется на 3000+ строк
- Дневные лимиты (3 публикации, 20 комментариев, 3 запроса в чат у нового аккаунта), повтор без двойного списания, дубликаты текста
- Возрастной допуск: личные сообщения незнакомым — только после проверки возраста обеих сторон
- Исправления v12: SOS в "Для вас", курсоры "Рядом" и "Для вас", фильтры карты до лимита, 5 избранных мест при параллельных запросах, уборка файлов с повтором, кэш приватных файлов
- Файлы публикуются только при включенной серверной проверке
- Протокол проверок: `QA_v14.md`. Этап 2 — встречи NEAR Meet (Host, заявки, групповой чат, упоминания, готовность)

## Версия 12

- Лента: "Новое", "Рядом", "Для вас", фильтры "сегодня / неделя / друзья" (запоминаются для каждого аккаунта); при обрыве сети остается последняя лента
- Карта: фильтры "горячее / друзья / сегодня / неделя", кнопка "Искать здесь", прошедшие события отдельным видом с пометкой "завершено"
- События по датам ("Сегодня", "Сб 28"), уведомления группируются ("Айгерим и еще 2")
- Избранные места (дом, работа): видите только вы, push о происшествиях рядом — только если включили
- Публиковать и писать можно после подтверждения почты; действие гостя продолжается после входа
- SOS: срок ставит сервер, два одновременных SOS невозможны; файлы проверяются на сервере (тип, размер, GPS в видео)
- Переписка удаленного аккаунта хранится у собеседника 30 дней
- Новое знакомство на 12 секунд с субтитрами RU/KZ, без движения — для "уменьшить движение" и экономии трафика
- Форма "Сообщить об ошибке", казахский перевод новых экранов, сжатые файлы приложения

## Версия 11 (подготовка к закрытой бете)

- Безопасность: профиль и роли только с сервера, скрытый контент не виден через API, минимальные права, push только к настоящим сервисам, лимиты частоты, удаление аккаунта задачей с повтором
- Модерация: вес жалоб с учетом доверия, журнал решений, апелляции, роль модератора отдельно от администратора, ИИ-проверка на сервере, файлы скрытых публикаций — в приватном бакете
- Лента и карта: PostGIS, одинаковые правила видимости, курсор без пропусков и дублей, режим карты "на экране" / "в радиусе"
- SOS: явный признак, срок 3 часа, подтверждение, кнопка 112, точное место только по согласию
- Сообщения: запросы от незнакомых, Realtime только для открытой переписки, статусы отправки
- Гость видит ленту без входа и без GPS; короткое знакомство; светлая, темная и системная темы; казахский язык (бета)
- Кэш по аккаунтам, WOFF2, ленивая карта, аналитика без персональных данных

## Структура

```
app.html            приложение
index.html          сайт-презентация
css/                стили
js/config.js        ключи Supabase (заполнить!)
js/data.js          работа с данными (Supabase или демо-режим)
src/app/            модули интерфейса (сборка: node tools/build.mjs)
js/app.js           интерфейс (собранный файл)
js/*.min.js, css/*.min.css  сжатые файлы, их подключает app.html
media/onb-ru.mp4, onb-kz.mp4  знакомство 12 с (RU/KZ) и кадры для статичного варианта
js/i18n.js          русский и казахский
supabase/schema.sql база данных: таблицы, права, хранилище, уведомления
supabase/functions/  moderate (ИИ, карантин, проверка файлов), push, delete-account
supabase/migrations/ версионные миграции (014_v14.sql — этап 1 v14; 014b_purge_legacy.sql — удаление старых имен и пола, отдельно)
supabase/tests/     автоматические проверки прав и функций
src/lib/clean.js    NEAR Clean (маскирование мата), вставляется в js/data.js сборкой
QA_v14.md           протокол проверок v14 (QA_v12.md, QA_v11.md — предыдущие)
SETUP.md            как подключить сервер, по шагам
```

## Технологии

HTML/CSS/JavaScript · Supabase (Auth, Postgres, Storage, Realtime) · MapLibre + OpenFreeMap · PostGIS · GitHub Pages

## Режимы

- **Демо** (по умолчанию, если `js/config.js` пустой): данные только на этом устройстве.
- **Сервер:** заполните `js/config.js` по инструкции из `SETUP.md`.

Разделы "Услуги", "Опросы", "Помощь рядом" и "Сообщества" пока работают как примеры, без сервера. Звонки — следующим этапом.
