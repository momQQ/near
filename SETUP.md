# Подключение сервера NEAR (Supabase)

Без этого шага приложение работает в **демо-режиме**: аккаунты и публикации хранятся только на одном телефоне.
После подключения Supabase все пользователи видят публикации друг друга, фото хранятся на сервере, а вход работает с любого устройства.

Время: около 15 минут. Бесплатно.

---

## Шаг 1. Создайте проект

1. Откройте https://supabase.com и нажмите **Start your project**. Войдите через GitHub (аккаунт momQQ).
2. Нажмите **New project**.
3. Заполните:
   - **Name:** `near`
   - **Database Password:** придумайте и сохраните (понадобится редко)
   - **Region:** ближайший, например `Central EU (Frankfurt)`
4. Нажмите **Create new project** и подождите 1–2 минуты.

## Шаг 2. Создайте таблицы

1. Слева откройте **SQL Editor** → **New query**.
2. Откройте файл `supabase/schema.sql` из архива, скопируйте **весь** текст и вставьте в окно.
3. Нажмите **Run**. Внизу должно появиться `Success. No rows returned`.

Скрипт создает таблицы, правила доступа, хранилище для фото и автоматические уведомления. Его можно запускать повторно.

## Шаг 3. Настройте вход по email

1. Слева **Authentication** → **URL Configuration**.
2. **Site URL:** `https://momqq.github.io/near/app.html`
3. В **Redirect URLs** нажмите **Add URL** и добавьте: `https://momqq.github.io/near/**`
4. Нажмите **Save**.

Это нужно, чтобы ссылки из писем (подтверждение почты, сброс пароля) открывали ваше приложение.

> **Для теста можно отключить подтверждение почты:** Authentication → Sign In / Providers → Email → выключите **Confirm email** → Save.
> Бесплатный почтовый сервер Supabase отправляет всего несколько писем в час. Для настоящего запуска подключите свой SMTP (Authentication → Emails → SMTP Settings).

## Шаг 4. Скопируйте ключи

1. Слева внизу **Project Settings** (шестеренка) → **API** (или кнопка **Connect** вверху).
2. Скопируйте:
   - **Project URL** — вида `https://abcdefgh.supabase.co`
   - ключ **anon public** (начинается с `eyJ...`) или **Publishable key** (`sb_publishable_...`)

⚠️ Ключ **service_role / secret** никуда не вставляйте и никому не показывайте.

## Шаг 5. Вставьте ключи в приложение

1. На GitHub откройте репозиторий → папка `js` → файл `config.js`.
2. Нажмите карандаш ✏️ (Edit).
3. Вставьте ключи между кавычками:

```js
SUPABASE_URL: "https://abcdefgh.supabase.co",
SUPABASE_ANON_KEY: "eyJhbGciOi...",
```

4. Нажмите **Commit changes**.
5. Через 1–2 минуты откройте `https://momqq.github.io/near/app.html`. Желтая плашка "Демо-режим" должна исчезнуть.

## Шаг 6. Проверьте

1. Зарегистрируйтесь (если подтверждение почты включено — откройте письмо и нажмите ссылку).
2. Создайте публикацию с фото.
3. В Supabase: **Table Editor → posts** — появилась строка; **Storage → post-media** — появилось фото.
4. Откройте приложение на другом телефоне под другим аккаунтом — публикация видна в ленте и на карте.

---

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| "Не удалось загрузить библиотеку Supabase" | Проверьте интернет и правильность `SUPABASE_URL` |
| "Invalid API key" / ничего не грузится | Скопируйте ключ заново, без пробелов и переносов |
| Письмо не приходит | Проверьте "Спам"; лимит бесплатных писем — несколько в час; для теста отключите Confirm email |
| Ссылка из письма открывает не то | Проверьте Шаг 3 (Site URL и Redirect URLs) |
| "Нет прав на это действие" | Запустите `schema.sql` еще раз целиком |
| Фото не загружается | Storage → проверьте, что есть бакет `post-media` (Public) |

Безопасность: ключ anon можно хранить в открытом коде — защиту обеспечивают правила доступа из `schema.sql` (каждый может менять только свои публикации, видеть только свои уведомления и сохраненное).
